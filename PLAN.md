# MVP completion plan

The active user request authorizes finishing the full demo beyond Phase 0.

1. Connect the existing lesson/session API to a complete React tutor.
2. Implement explicit screen capture, current control inspection and a passive pointer for Photopea and the practice canvas.
3. Add opt-in browser voice commands, speech output and text fallback.
4. Add server-only Gemini video extraction and screenshot tutoring, with bounded validated responses. Keep a visibly labeled deterministic practice mode for demos without credits.
5. Finish setup, demo instructions, meaningful tests and independent QA before committing or pushing.

Scope: the Photopea text workflow and equivalent practice canvas. Arbitrary sites, playlists, desktop overlays, and full course ingestion remain outside this MVP.
