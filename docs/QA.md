# Workspace launch verification

The prepared lesson was exercised in Chromium with the unpacked extension and the local dashboard. Launching opened Photopea in a separate tab. The overlay displayed the first instruction, advanced on **Mark step done**, and restored the current step after reload. After the tutorial, a follow-up task entered on the dashboard appeared in the overlay and could be marked complete.

The automated suite covers supported software identifiers, unsupported video handling, tutor evidence and session validation, toolbar behavior, and the legacy sandbox state fixture. Live Gemini extraction, screenshot feedback, microphone input, and signed-in Canva and Figma workflows require separate verification.
